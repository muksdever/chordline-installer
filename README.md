## How to install

1. **Download** [ChordlineInstaller.exe](https://github.com/muksdever/chordline/releases/latest/download/ChordlineInstaller.exe) and open it.
2. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**. The installer isn't code-signed, so SmartScreen doesn't recognise it yet.
3. Pick **Discord**, **Discord PTB** or **Discord Canary** and click **Install**. Discord restarts with Chordline loaded.

To update, run the installer again and click **Update**, or use **Chordline Settings → Updater** inside Discord.
To remove Chordline, open the installer and click **Uninstall**.

### Antivirus warning?

The installer is built automatically by GitHub from the [public source code](https://github.com/muksdever/chordline/tree/main/installer), but it isn't code-signed.
Because it downloads files and edits Discord's files, some antivirus programs (especially Windows Defender's `!ml` detections) can flag it by mistake.
If that happens, tell the person who sent you Chordline before running it.
